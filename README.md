# SOUL STAY HOUSE

종교와 무관하게 누구나 이용하는 온라인 명상의 집.

## 실행
```bash
npm install
npm run dev
```

## 검증
```bash
npm run typecheck
npm run build
```

## 현재 범위
- 숲속/바다/비 오는 집, 브라우저 합성 사운드, 오디오 믹서 및 로컬 프리셋
- 비공개 로컬 마음 기록과 명상 타이머
- Vite + TypeScript 부트스트랩 적용. **기존 `script.js`는 아직 JavaScript이며 TypeScript 모듈로 완전 전환되지 않았습니다.**
- 실제 음원 파일, 계정/DB, 공동 명상 서버, 상용 결제는 연결하지 않았습니다.

## 개발지침
`AGENTS.md` 및 `docs/CODEX_FIRST_TASK.md` 참조. 기존 `soul-stay-garden` 저장소 수정 금지.
