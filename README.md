# SOUL STAY HOUSE

종교 중립형 온라인 명상의 집 — Codex 개발용 **1차 실행 가능한 정적 웹 프로토타입**.

## 실행

Python 3가 설치되어 있다면 프로젝트 폴더에서:

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다. 또는 `index.html`을 직접 열어도 됩니다.

## 지금 작동하는 기능

- 3개 명상의 집 선택 / 간단한 CSS 풍경
- 실제 Web Audio API 오디오: 직접 합성한 부드러운 음색, 빗소리, 바람소리 (제3자 음악 사용 없음)
- 각 소리 믹싱, 전체 음량, 일시정지, 타이머
- 페이지 이동 중 공통 오디오 유지
- 로컬 프리셋 저장
- 로컬 비공개 마음 기록장 / 삭제 / JSON 내보내기
- 20분 개인 명상 타이머
- 모바일 반응형 화면
