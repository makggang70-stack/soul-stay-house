# Codex instructions: SOUL STAY HOUSE

## Product
A Korean-first, religion-neutral digital quiet house. Core user flow: choose nature scene, listen to continuous ambient sound, mix own sound, save private journal, optional peaceful shared meditation (later).

## Non-negotiable
1. Keep audio playing across in-app navigation. Do not autoplay without user gesture.
2. Do not embed or download copyrighted recordings without clear rights. Existing audio is original synthesized ambient sound, not recordings.
3. Never fake live participants or imply a local-only feature is synced online.
4. Journal defaults to private. Do not log journal text to telemetry.
5. Accessible keyboard navigation, visible focus, mobile support, reduced-motion compliance.
6. No secrets in code or git; introduce `.env.example` and `.gitignore` as needed.
7. Implement the smallest working vertical slice first. Test, report actual output and known limitations.
8. Do not delete or repurpose the separate SOUL STAY GARDEN project.

## Current stack
Vite + strict TypeScript with dependency-free DOM UI. Migrate frameworks only with a clear testable need.

## Workflow
Read README and docs/CODEX_FIRST_TASK.md. Make a plan, implement, run checks, review git diff, document status. Keep commits scoped.
